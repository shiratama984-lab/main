# Windows V26.60 実機確認（未実施）

この一覧は未実施の受け入れ確認です。完了済みの結果ではありません。

- mcaddonを読み込み、両パックが一覧に表示される。
- 内容ログにmanifest、Script API依存、ブロック、エンティティ、描画定義のエラーがない。
- 杖の地面への右クリック、および `/scriptevent millenaire:menu` でフォームが開く。
- 管理者タグがないプレイヤーが村を設立できない。
- 7文化それぞれを離れた平坦な場所に設立し、中心建築と住居が完成する。
- 屋根・階段・扉・土壁・茅葺き・住民の顔と衣服が表示される。
- 住民3人に右クリックでき、村情報と交易画面が開く。
- 小麦16個を売ると在庫が16減り残高が8増える。不足時は何も失われない。
- パン8個を購入すると残高が8減り、在庫が8増える。満杯時は課金されない。
- 資材納入で原木／丸石が移り、必要量を納めると次の住居が完成する。
- 小麦32個の依頼を完了して報酬を受け取り、二重に受け取れない。
- 建築途中でワールドを終了し、再入場後に正しい位置から続く。
- 遠くに移動して建築を停止させ、戻って再開できる。
- ワールドを保存・再入場し、村名、文化、建築、所持金、評判が残る。
- 別プレイヤーの残高と依頼状態が分離され、同じ村の資材は共有される。
