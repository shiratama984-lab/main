# ファンタジーRPG 制作方針案

これは参考アドオン調査に基づく**設計案**であり、実装済み機能の一覧ではありません。

## 中心となる遊び

探索・採集・魔物討伐 → 経験値と素材を獲得 → 装備・魔法を強化 → 依頼と交易で収入 → 自分の店・ギルド拠点 → 仲間と王国を設立 → 領地を発展させて襲撃から守る。

初めは個人で進められ、経済と建国を冒険の先に接続する。マルチプレイ時には送金、ギルド、国民・権限管理を利用できる設計にする。

## 画面の方向

- 冒険者手帳: 紙・革・金属の枠を用いた6アイコンの入口。
- 人物: レベル、経験値、戦闘能力、生活職の成長。
- 魔法書: 習得魔法、説明、消費MP、再使用時間、選択状態。
- 依頼帳: 討伐・採集・納品、達成進捗、報酬受領。
- 市場: 商品画像のグリッド、価格・所持金、購入数の入力と確認。
- 王国台帳: 国名、国庫、領地、国民、役職、権限。
- HUD: HP・MP・経験値、選択魔法。画面を圧迫しない配置。

参考のスマホや銃アイコンをファンタジー世界へ直接置くのではなく、画像を重ねる構成、アイコンでの選択、画面分岐を応用する。

## 初回の縦につながった体験

1. 冒険者手帳から状態と依頼を確認。
2. 戦士・魔法使い・弓使いの方向性を表現できる基本装備。
3. MPと再使用時間を持つ少数の魔法。
4. 魔物を倒して経験値と素材を獲得。
5. 依頼を達成し、素材を売って装備を購入。
6. 拠点用の土地を取得し、王国を設立。国庫・国民管理までつなぐ。
7. 保存・再入場で進捗を保持。

外交、国同士の戦争、プレイヤー市場、複雑な生産・施設の自動運転は、この基本体験が動いた後に拡張する候補。

## 検証の区別

- 自動検証: 金額と在庫、魔法の消費と再使用制限、依頼報酬の重複、権限、領地重複、保存復元。
- 実機検証: Windows V26.60のAPI、JSON UIの表示と選択番号、GUI倍率、HUD、投射物と敵AI、再入場、複数プレイヤー。
- 画像だけのプレビューは実ゲームのUI表示確認の代用とはしない。
