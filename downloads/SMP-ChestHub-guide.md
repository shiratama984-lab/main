# SMP Chest Hub 0.1.0

バニラのサバイバルに、**54スロットのチェスト型メニュー、オークション、経済、ホーム、土地共有**を加える独立した統合版アドオンです。RPG版やMillénaire版とはUUID・保存キー・通貨が異なります。素材とコードは本プロジェクトで制作したものです。

対象希望環境: Windows Minecraft統合版 V26.60。安定版Script API 2.0.0／UI 2.0.0を使っています。**実際のMinecraft内での表示・操作は未検証**です。公開SMPサーバーへ導入する前にテスト用ワールドで確認してください。

## ダウンロードと導入

[アドオンをダウンロード](https://github.com/shiratama984-lab/main/raw/refs/heads/main/downloads/SMP-ChestHub-0.1.0.mcaddon)

1. `.mcaddon` をダブルクリックしてMinecraftにインポートします。
2. バックアップ済みのテスト用ワールドで、ビヘイビアーとリソースの **SMP Chest Hub** 両パックを有効にします。
3. リソースパックの歯車で **「チェスト型UI」** を選びます。ベータAPIは不要の設計です。
4. 初参加時に渡される **SMPメニュー** を使います。空中使用が機能しない場合は、手に持って地面を右クリックします。
5. 支給やアイテム操作で開けない場合、チートを有効にして `/scriptevent smp:menu` で開けます。`/give @s smp:menu` でも取得できます。

無料メニュー支給は1人1回です。紛失時は **コンパス＋チェスト** で再制作できます。一般機能に管理者タグは必要ありません。土地保護を管理上の理由で無視する場合だけ `/tag @s add smp.admin` を使えます。

## チェストUI

- メイン・オークション一覧・詳細・受け取りBOX・ショップ・ウォレット・ホーム・土地・ガイドを9列×6行で表示。
- アイコンにマウスを重ねると、名称・価格・個数・説明を表示する定義です。
- アイテムをクリックして選ぶメニューです。通常チェストのドラッグ、分割、Shiftクリックで実際のアイテムを移す仕組みではありません。
- 個数・価格・名前の入力と最終確認は標準フォームを使います。
- 一覧は45件ずつページ分けし、最下段を戻る・出品・受け取り等に使います。
- 専用画像がない素材は荷物アイコンで表示します。正確なアイテムID・個数は説明に表示します。

UIが崩れた場合は、RPの歯車で **「標準UI（互換モード）」** に切り替え、再入場してください。続いて `/scriptevent smp:standard` を実行すると、空欄を省いた標準リストで操作できます。`/scriptevent smp:chest` と「チェスト型UI」の選択で元へ戻せます。正常に開ける場合はガイド内でも表示モードを切り替えられます。

`server_form`を書き換える他のRPとは表示が競合する可能性があります。最初はこのSMPパック単独で確認してください。RPG版と同時使用する場合も、双方の独自UIが同時に有効になる保証はありません。

## オークション

### 出品

「オークション」→最下段の「アイテムを出品」→インベントリのスロットを選びます。個数・開始価格・任意の即決価格・期間を入力し、確認すると実物をインベントリから預かります。

- 初版の対象は通常の素材・鉱物・食料・ブロック等の許可リスト内アイテム。
- 名前、説明文、Dynamic Properties、Adventure用制約、ロック、死亡時保持、その他の特殊データがある物は拒否します。
- 装備、エンチャント装備、書き込まれた本、シュルカーボックス等の容器、独自アドオンのアイテムは対象外です。データを消して通常品として出品する処理はしません。
- 出品量は選んだ1スタック以内です。手数料はありません。
- 開始・即決価格は1〜1,000,000 C。即決は開始価格以上です。空欄にすると即決なし。
- 期間は5分・30分・2時間・24時間。同時出品は1人5件まで。

### 入札と即決

- 最初の入札額は開始価格以上、その後は現在額の5%以上を上乗せ（最低+1 C）。
- 最高入札額は口座から一時的に差し引き、オークションの預り金として保存します。
- 別の人が上回ると、前の人へ自動返金。同じ最高入札者の増額は差額だけを引きます。
- 自分の出品への入札、期限切れへの入札、残高不足、古い価格での操作は受け付けません。
- 即決価格以上の入札は即決価格で終了します。即決購入ボタンもあります。
- 入札後の取り消しはできません。出品者による取り消しも入札のない間だけです。

### 終了と受け取り

- 落札成立時、代金は売り手の口座に自動入金し、品物は落札者の受け取りBOXへ送ります。
- 入札なしの期限切れや取消品は、売り手の受け取りBOXへ返します。
- BOXは満杯のインベントリへの回収を取り消し、品物を預かったままにします。空きを作って再回収できます。
- 入金・返金は受け手がオフラインでも保存済み口座へ反映します。
- 期限は現実時間です。ワールドが止まっている間に期限を過ぎた出品は、次の開始時に精算します。ゲーム内の時間変更や睡眠で期限は早まりません。
- 終了記録はアイテム回収が済むまで保持し、回収後は削除します。長期の売買履歴は未実装です。

## 経済

- 通貨は整数の **C**。このSMPパック専用で、他パックとの残高連携はしません。
- 初回登録100 C、デイリーボーナス100 C。更新は日本時間0時です。
- サーバーショップで原木・丸石・小麦・鉄・ダイヤ・パン・松明を売買できます。
- ウォレットからオンラインの相手を選んで送金できます。確定時に相手が離脱しても、登録済み口座へ送る方式です。
- オークション売上・返金に受取操作は不要。アイテムだけBOXから回収します。
- 死亡時の通貨減少や経験値への干渉はありません。

## ホーム・土地

- ホーム3件。現在の場所を名前付きで保存・上書き・削除できます。
- ホーム／ワールドスポーンへの移動は5秒待機。移動・被ダメージ・退出で待機を取り消します。成功後30秒の再使用制限は保存されます。
- 移動先には読み込まれた地面と2ブロックの空間が必要です。未読み込みや危険な足元、権限のない私有地には移動しません。自動チャンク読み込みはしません。
- オーバーワールドの16×16区画を200 Cで購入。1人4区画まで、共有者8人まで。
- 通常のブロック破壊・右クリック操作を事前イベントで止め、境界をまたぐ設置も判定。爆発の破壊対象から私有地ブロックを外します。
- 土地放棄では建物は消しませんが、購入費は戻らず、共有も解除します。
- ピストン、液体、火災、ディスペンサー等の全自動機構や特殊な設置経路を網羅した保護ではありません。荒らし対策として検証済みとは主張しません。
- TPA、RTP、プレイヤー間の直接物々交換、クラン、給与、管理GUI、バニラチェストショップはこの初版に含みません。

## 保存と初版の上限

保存キーは `smp:save_v1`。全口座・入札預り金・出品品・受け取り・土地・ホーム・デイリー状態をDynamic Propertiesへ保存します。

- 登録32人、出品と未回収品を合わせて48件、土地全体64区画。
- 保存はUTF-8で30,000バイトまで。上限に達するとその操作を取り消します。終了・精算に必要な領域は未終了出品の数に応じて予約し、新規データが精算領域を使い切らないようにします。
- 通貨の総発行上限は10億 C。全口座と入札預り金の合計を毎回検査します。
- 取引の同一処理内で保存・在庫操作が失敗した場合、状態とインベントリのスナップショットへ戻します。
- 壊れた保存データは自動初期化しません。読み込みに失敗すると変更・保護対象の操作を止めます。

これらはスクリプト内の同期処理と例外時の復元です。Minecraftプロセスの強制終了、ストレージ障害、別アドオンの書き換えまで完全に原子的にする保証はありません。大規模な公開サーバー向けの無制限データベースではありません。

## 開発と検証

Node.js 24とPython 3.12で確認しています。添付された参考アドオンは不要です。

```sh
cd smp
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

画像と定義の再生成: `npm run assets`。出力先: `dist/SMP-ChestHub-0.1.0.mcaddon` と編集用ソースZIP。

API型検査、オークション・預り金・返金・期限・回収・保存失敗・在庫不足・移動・土地権限などの自動試験を実行しています。実ゲームのJSON UI、マウス操作、複数クライアント、アイテムAPIの動作確認は `TESTING.md` の項目で別途必要です。
