# 冒険と王国 RPG 0.1.0

剣・魔法・素材売買・依頼・王国運営をつないだ、統合版向けの独立した試作アドオンです。ゲリラ・MOBRIA・MakeCountryの構成を参考に、新しいコードと画像を制作しています。参考アドオンやMillénaireの画像・スクリプトはこのパッケージに含みません。

対象希望環境: **Windows Minecraft統合版 V26.60**。公式の安定版Script API 2.0.0／UI 2.0.0を使います。Minecraft実機での読み込み・描画・操作は未確認です。自動試験はMinecraftエンジンの代用ではありません。

## ダウンロードと導入

[アドオンをダウンロード](https://github.com/shiratama984-lab/main/raw/refs/heads/main/downloads/AdventureKingdom-RPG-0.1.0.mcaddon)

1. `.mcaddon`をダブルクリックし、Minecraftにインポートします。
2. バックアップ済みの新しいテスト用ワールドで「冒険と王国 RPG」と「冒険と王国 RPG — 画像とUI」の両パックを有効にします。
3. リソースパックの歯車から「画像UI」を選びます。難易度はイージー以上に設定します。ベータAPIは不要の設計です。
4. 最初の参加時に「冒険者手帳」を支給します。使うか、手に持って地面を右クリックしてください。
5. 自動支給や空中使用が機能しない場合、チートを有効にして `/scriptevent arpg:menu` で直接開けます。`/give @s arpg:adventure_book` でも取得できます。
6. 「人物・装備」から戦士・魔法使い・弓使いを選び、初期装備を受け取ります。選択は各プレイヤー1回です。

ゲーム内では一般プレイヤーに管理者タグは不要です。領地を管理上の理由で操作する場合のみ、管理者が `/tag @s add arpg.admin` を使用できます。

## 最初の進め方

- 野盗・影の魔物・バニラの敵を倒すと、経験値と少量のGを獲得。動物を倒しても報酬は出ません。
- 依頼は討伐3体、小麦32個、鉄8個の3件。各依頼は1人1回で、手帳から達成報告・納品して報酬を受け取ります。
- 市場で原木・小麦・丸石・鉄を売り、パン・剣・杖・矢を買えます。数は「組数」を入力します。パン1組は8個です。
- 魔法書で選択した魔法を「樫の杖」で発動します。杖も地面への右クリックが代替操作になります。
- 300Gを集めて王国を設立すると、立っている16×16の区画が最初の領地になります。
- 国庫へ入金し、自国領の辺に接する区画を1つ80Gで購入できます。王国は手帳から加入申請・国王の承認で参加します。
- 国王は自国領で防衛戦を開始できます。開始費は国庫40G、野盗3体を倒すと国庫へ60G。国王が開始地点から48ブロック以内にいると1秒に1体ずつ出現します。地面が見つからない場合は出現を止めて通知します。平らな場所で開始してください。

## 初期職業と魔法

|職業|初期装備|基本最大MP|
|---|---|---:|
|戦士|冒険者の剣・盾・パン8個|30|
|魔法使い|樫の杖・パン8個|60|
|弓使い|弓・矢32本・パン8個|40|

職業で魔法使用を禁止していません。どの職業でも杖を購入・制作して使用できます。レベルごとに最大MPが3増え、MPはオンライン時に毎秒1回復。レベル上限50です。

|魔法|解放|MP|再使用|効果|
|---|---:|---:|---:|---|
|火炎弾|Lv1|8|2.4秒|視線の先14ブロック以内の魔物1体へ基本7ダメージ|
|氷結|Lv3|12|4秒|12ブロック以内の魔物1体へ基本5ダメージと鈍足4秒|
|癒やし|Lv1|14|8秒|自分のHPを6回復|

攻撃魔法は炎上・爆発を起こさず、プレイヤーを対象にしません。魔法の攻撃処理は視線判定とダメージ、着弾位置の粒子によるものです。飛ぶ3D弾体・詠唱アニメーションはありません。通常の剣や弓のPvPはMinecraft側の設定に従うため、PvP不要の場合はワールド設定で無効にしてください。

## 画像付きUI

- 冒険者手帳: 羊皮紙背景、3列×2行のオリジナルアイコン。
- 市場: 3列×3行の商品と銀行への入口。
- 内側の詳細・入力・確認画面: 読みやすさを優先した標準フォーム。
- HUD: HP、MP、レベル、所持金、選択魔法、現在地の領有国をアクションバーへ表示。
- UI・人物の画像は独自に制作したピクセル絵です。参考アドオンの画像は同梱していません。

画像UIの表示が崩れたりボタンが押せない場合、リソースパックの歯車からサブパックを**「標準UI（互換モード）」**へ切り替え、ワールドに入り直してください。標準フォームでも同じ機能へアクセスできます。メインパックの「画像UI」を選ぶと画像付き画面へ戻せます。

`server_form`を改変する他のリソースパックとは競合する可能性があります。最初は参考アドオン等を同時に有効化せず、本パックだけで確認してください。他パックと組み合わせた表示は未検証です。

## 王国と領地の初版仕様

- 国王、執政官、国民の3役職。国王が加入申請の承認と役職変更を行います。
- 領地購入は国王・執政官、国庫への入金は国民全員が可能。国庫から個人口座への引き出しは未実装です。
- 国民は領内のブロック操作・コンテナ操作が可能です。国民以外の破壊・通常の右クリック操作は事前イベントで止めます。領地境界への隣接設置も判定します。
- 魔法による他国領内の敵への攻撃を禁止し、領内ブロックを爆発の破壊対象から外します。
- ピストン・液体・火災・ディスペンサー等の全自動機構と全アイテムの特殊操作を網羅した土地保護ではありません。公開サーバーでの荒らし対策として検証済みとは主張しません。
- 国王の脱退、解散、王位移譲、外交・国同士の戦争、自動課税、競売、NPC商店、ダンジョン、生活職別のレベルは未実装です。
- 防衛戦の敵は死亡を記録します。見失った場合や継続できない場合は国王が降参して終了できます。国王や防衛地点付近が読み込まれていない間は敵の追加出現を止めます。
- 初版の上限: 登録48人、8王国、各国16区画。保存JSONのUTF-8容量は30,000バイトまで。容量が先に上限に達した場合、その操作を取り消して通知します。

## 保存とアイテム処理

保存キーは `arpg:save_v1`。Millénaire版と分離しています。通貨・国庫・MP・経験値・依頼・職業・国民・領地・防衛戦の進捗をワールドのDynamic Propertiesへ保存します。金額は整数Gです。

同一スクリプト内の取引は同期処理とし、保存失敗・在庫不足・収納失敗時には所持金とインベントリを元へ戻す処理があります。保存が壊れている場合は自動初期化せず停止します。Minecraftプロセスの強制終了や別アドオンによる書き換えに対して、完全なトランザクションを保証するものではありません。

初期職業装備と手帳の無料支給は1回です。紛失時の制作:

- 冒険者手帳 = 本 + エメラルド
- 樫の杖 = 棒2 + アメジストの欠片
- 冒険者の剣 = 鉄インゴット3 + 棒

## 開発と検証

Node.js 24、Python 3.12、公式API型定義で確認しています。

```sh
cd rpg
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

画像・JSON定義の再生成は `npm run assets`。元の添付アドオンやJARは不要です。

自動試験は、残高、在庫、確認後の売買、保存失敗からの復旧、依頼報酬、魔法条件、領地境界・権限、防衛戦、保存復元、UIボタン番号と画像参照を検証します。実ゲーム内の見た目・クリック・敵AI・自然スポーン・複数クライアントは未検証です。
