# Windows V26.60 実機確認（未実施）

- BP/RPを読み込み、内容ログに依存API・アイテム・JSON UIエラーがない。
- チェスト型UIで54枠とアイコン、マウスホバーの説明が表示される。GUI倍率を変えて操作できる。
- 表示に対応したスロットが動き、空欄は操作を実行しない。標準UIモードでも同じ機能を使える。
- 手帳の空中使用・地面使用でメニューを開ける。両イベントが起きても画面が二重に開かない。
- 通常素材の出品で正確な個数だけが移り、取消でBOXへ戻る。
- 名付け、説明、特殊データ、装備、容器等の非対応品を出品できない。
- 2人以上で入札し、前の入札者へ返金。同じ人の増額は差額のみ。
- 同じ出品に同時に即決し、購入者と売上が重複しない。
- 期限前後に入札、取消、再入場を行い、精算が1回になる。
- 売り手・買い手が退出しても売上、返金、受け取り先を保存する。
- BOX回収を満杯で失敗させ、空きを作って回収できる。重複回収できない。
- ショップ売買・送金・デイリーで残高とアイテムが一致する。
- ホーム移動が5秒後に発動し、移動・被ダメージ・退出で中止される。
- 移動先にブロックを置いた場合、未読み込み、危険な足元、私有地化で移動を中止する。
- 土地を購入して、他人の破壊・設置・コンテナ操作と共有者の操作を確認。
- 保存・退出・再入場でオークション・残高・ホーム・共有を保持する。

自動試験・型検査の合格を、この実機確認の合格とは扱わないこと。
