添付された Millénaire 9.0.3 のデータを参考・変換した、非公式の統合版アドオン試作版です。完全移植ではありません。対象希望環境は Windows 統合版 V26.60 です。Minecraft 実機でのインポート・描画・操作は未検証です。

## Windows への導入

1. `dist/Millenaire-Bedrock-0.1.0.mcaddon` をダブルクリックし Minecraft で読み込みます。
2. バックアップ済みのテスト用ワールドを用意します。「ビヘイビアーパック」と「リソースパック」の両方を有効にします。
3. チートを有効にします。製品版の Script API 2.0.0 を使用し、ベータAPIの有効化は想定していません。
4. チャットから次のコマンドを実行します。

```mcfunction
/tag @s add millenaire.admin
/give @s millenaire:summoning_wand 1
```

5. 杖を手に持って地面を右クリックすると「村の案内」が開きます。空中使用でも開く設計ですが、開かない場合は地面をクリックしてください。代替コマンドは `/scriptevent millenaire:menu` です。
6. オーバーワールドの**平坦な、周辺100×100ブロックに建物がない場所**で「新しい村を設立」を選び、文化・村名を入力して地形変更に同意します。生成は既存ブロックを上書きし、元に戻す機能はありません。
7. 生成中は村の中心から64ブロック以内に留まってください。最初に中心建築、次に住居1棟を生成します。停止時は中心付近に戻り、杖の「近くの村の情報」→「村の建築を再開」を選びます。
8. 住民を右クリックして住民情報・交易を開きます。村の記録から資材納入と次の住居の建築ができます。

最初の所持金は0デニールです。小麦・原木・丸石を売るか、村長の依頼で増やせます。通貨と評判はプレイヤー・村ごとの記録で、物理アイテムではありません。通常の空きスロットを用意して購入してください。

## 収録内容

- ノルマン・日本・インド・マヤ・ビザンティン・セルジューク・イヌイットの7文化。
- JAR内の建築NBTから変換した、各文化の中心建築1種・住居1種、計14種。全15,457ブロック配置を収録。
- JAR内の住民テクスチャ21種。統合版用に用意した人型モデル、歩行アニメーションで表示。
- 元の召喚の杖・文化アイコン・土壁・日干しレンガ・茅葺きのテクスチャ。
- 日本語の村案内、文化の書、村の記録、住民情報、交易、資材納入、簡易依頼のフォームUI。
- 段階的なブロック配置、資材消費による住居追加、交易、村ごとの評判、ワールドへの保存。
- 初版では最大8村、1村につき住居3棟・住民3人。住居は同じ設計を繰り返します。

## 元MODとの差分・制限

- **元の羊皮紙風画面・タブ・ドラッグ式交易画面は未再現**です。Script API の標準フォームUIを使用します。文化アイコンと画面の役割を取り込みましたが、画面配置の完全再現ではありません。
- 7文化の全建築・衣服レイヤー・全住民タイプは含みません。取り込んだ住民の役職と名前は初版用の割り当てです。
- ブロックIDと階段・原木・ハーフブロック・扉・ベッド・松明・トラップドアの状態を変換します。その他の状態、チェスト内容、看板文字、装飾、Javaのブロックエンティティ情報は引き継ぎません。専用ブロックの一部は代用品になります。`IMPORT_REPORT.json` に元建築と置換を記録しています。
- 自然生成、地形への自動適応・整地、道の自動接続、住民の採集・物流・自律建築AI、家族や人口成長、外交、軍事、世界クエスト、全アイテムは未移植です。
- 建築は住民が実際に運ぶ方式ではなくスクリプトによる順次配置です。住民は基本的な散歩・注視を行います。建築資材・価格・依頼は独自の簡易設定です。
- ワールド保存にはDynamic Propertiesを使用します。建築進行は5秒ごとにも保存するため、異常終了時には直近の配置が再実行される場合があります。
- 実ゲームの描画、地形、ブロック状態の挙動、複数クライアント接続は未検証です。APIの型検査やモック試験は実機動作の保証にはなりません。

## 開発と検証

Node.js 24、Python 3.12 で検証しました。生成済みデータを同梱しているため、通常のビルドに元JARは不要です。

```sh
cd /workspace/main
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

`npm run check` は Script API 2.0.0 の公式型定義による検査です。`npm test` は内容の整合性、在庫処理、モック環境での建築停止・保存・再開・完了と交易UIの分岐を検証します。Minecraftエンジン上の試験ではありません。

元JARから再変換する場合:

```sh
python3 tools/import_jar.py /path/to/millenaire-9.0.3.jar
python3 tools/generate_packs.py
npm run check
npm test
npm run build
```

既存のチェックアウトを使います。別のGit worktreeは必要ありません。ゲーム内の表示確認には `docs/実機確認.md` を使用してください。
